# Медиа для демонстрации

Шесть изображений и шесть видео взяты из предоставленной пользователем
папки `C:\lr-rip\pics`. Исходные форматы сохранены, названия приведены
к именам услуг. Эти файлы хранятся в Git вместе с кодом.

После создания схемы БД и запуска контейнеров выполните из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\load-demo-media.ps1
```

Команда загружает файлы в публичный бакет `utilities` и обновляет ссылки
изображений шести демонстрационных услуг. Статусы, тарифы, лайки и
пользователи не сбрасываются. Для HTTP-приложения файлы раздаёт MinIO.

Источники и права на присланные материалы не установлены. Перед публикацией
репозитория проверьте право распространять эти изображения и видео.
